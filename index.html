Privacy Policy for Your Text Expander

Effective date: December 2025

Your Text Expander is a browser extension that helps users expand saved text snippets while typing on supported web pages.

What data the extension processes

  • Text typed into editable fields, only to detect snippet triggers and insert expansions
  • Configuration data such as API base URL, WebSocket URL, selected dataset, selected columns, and extension preferences
  • Authentication token used to connect the extension to the user's account
  • Snippet and dataset data retrieved from the configured backend service

How data is used

  • To detect snippet triggers while the user is typing
  • To retrieve snippet data from the configured backend service
  • To insert the selected expansion into the active text field
  • To keep snippet data synchronized with the backend

We do not sell personal information.

We do not use extension data for advertising.

Where data is stored

The extension stores configuration and cached snippet data locally using Chrome extension storage on the user's device.

Data sent to servers

The extension sends requests to the configured backend service in order to authenticate the session, retrieve datasets and rows, and receive update events over WebSocket.

Sharing of data

We do not share user data with third parties except when necessary to provide the extension's core functionality through the configured backend service, when required by law, or when necessary to protect the security, integrity, or operation of the service.

User choices

  • Users can disconnect or reconfigure the extension
  • Users can clear stored configuration from the extension options page
  • Users can uninstall the extension at any time

Security

We use reasonable safeguards to protect data in transit and at rest. Users should only connect the extension to trusted HTTPS services.

Children's privacy

This extension is not directed to children.

Changes to this policy

We may update this Privacy Policy from time to time. Updates will be posted at this URL with a revised effective date.
